WDV221 • User Defined Objects

User-defined objects: the basic pattern

Follow along as we build a small campus-club directory using user-defined objects.

Start a new HTML file. Type each code block as it is demonstrated, then run it before moving to the next block.

1. Arrays hold the source data

These arrays describe three clubs. The value at index 0 belongs with the other values at index 0.

Run this first:

let clubNames = ["Robotics Club", "Photography Circle", "Community Garden"];
let meetingDays = ["Tuesday", "Thursday", "Saturday"];
let memberCounts = [16, 9, 20];

2. An object groups related values

An object literal uses curly braces and property names to describe one thing.

Run this next:

let clubA = {
  club_name: clubNames[0],
  meeting_day: meetingDays[0],
  member_count: memberCounts[0]
};

Use dot notation to read a property:

Run these property checks:

console.log(clubA.club_name);
console.log(clubA.member_count);

3. A method gives an object behavior

A method is a function written inside an object. The keyword this refers to the object using the method.

Add the method, then run the test:

clubA.availableSpots = function() {
  return 20 - this.member_count;
};

console.log(clubA.availableSpots());

The method uses the current club’s member count. In the same file, create clubB and clubC with the same three properties and method, using indexes 1 and 2.

For the demonstration, the remaining objects can be created like this:

let clubB = {
  club_name: clubNames[1],
  meeting_day: meetingDays[1],
  member_count: memberCounts[1],
  availableSpots: function() {
    return 20 - this.member_count;
  }
};

let clubC = {
  club_name: clubNames[2],
  meeting_day: meetingDays[2],
  member_count: memberCounts[2],
  availableSpots: function() {
    return 20 - this.member_count;
  }
};

4. An object can contain an array of objects

Once you have three club objects, place them in an array inside another object.

Run this collection code:

let clubDirectory = {
  clubs: [clubA, clubB, clubC]
};

clubDirectory is an object. Its clubs property is an array, and each item in that array is another object.

5. A loop repeats the same work

The loop visits each object in the array. The variable club represents the current object for that pass.

Run this loop:

clubDirectory.clubs.forEach(function(club) {
  console.log(club.club_name);
  console.log(club.availableSpots());
});

6. JSON stores the data as text

JSON.stringify converts a JavaScript object into JSON text. JSON keeps the data, but not the JavaScript method.

Run these JSON conversions:

let clubAJSON = JSON.stringify(clubA);
let clubDirectoryJSON = JSON.stringify(clubDirectory);

console.log(clubA);
console.log(clubAJSON);
console.log(clubDirectoryJSON);

Result

The completed activity has three club objects, one method on each object, a directory object containing the clubs, loop-based output, and JavaScript-to-JSON conversions.
