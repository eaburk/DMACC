Flexbox Item Playground

Directions

Complete each part by editing only the CSS.

  1. Order
    Without changing the HTML:
    • Make Box 5 appear first.
    • Make Box 3 appear second.
    • Make Box 1 appear last.
  2. Flex Grow
    Give each box a different flex-grow value.
    • Box 1 = 1
    • Box 2 = 2
    • Box 3 = 3
    • Box 4 = 4
    • Box 5 = 5
  3. Flex Basis
    Experiment with:
    • 100px
    • 150px
    • 250px
    Observe how the boxes change.
  4. Flex Shrink
    Reduce the container width to 500px and prevent only Box 3 from shrinking.
  5. Align Self
    Move only Box 4:
    • flex-start
    • center
    • flex-end
  6. Challenge
    Create all of the following:
    • Box 5 appears first.
    • Box 2 is twice as wide as every other box.
    • Box 3 stays at the bottom.
    • Box 4 appears last.
